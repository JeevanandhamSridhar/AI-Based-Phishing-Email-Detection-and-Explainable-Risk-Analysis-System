---

## 1. Academic Positioning & Research Framing

> *"In the literature reviewed for this project, we did not find a single locally-deployable, budget-constrained student system that combines multi-signal explainable phishing risk scoring with an explicit AI-authorship indicator and a self-directed adversarial evasion test. The individual techniques are established; the integration and the honest reporting of their limits is the contribution."*  
> — *Extract from [`docs/research-gap.md`](docs/research-gap.md)*

This project explicitly avoids claims of "first ever." Standard email phishing detection pipelines combining headers, URL checks, TF-IDF/transformers, and SHAP/LIME are well documented in academic literature (e.g., EXPLICATE, 2025; ETASR, 2025). This project contributes two novel, first-class modules:

1. **AI-Generated / LLM-Authored Phishing Identification (Module A):** An 18-feature stylometric classifier detecting whether text was generated by an LLM vs. written by a human, evaluated both in-generator and across held-out generator models to honestly document cross-model generalization degradation.
2. **Explanation-Guided Adversarial Self-Evaluation (Module B):** An adversarial evaluation harness that systematically neutralizes the model's own top SHAP/LIME triggers through semantic paraphrasing, recording real evasion rates and demonstrating multi-signal defense-in-depth.

---

## 2. Strict Defensive Safety Guarantees

This system is engineered strictly as a passive, defensive analytical instrument. Under no circumstances will the system:
- **Execute Attachments:** Files are inspected passively for file extension, double extensions, MIME type mismatches, and SHA-256 digest. No macros, binaries, or scripts are executed.
- **Fetch or Visit URLs:** Links are analyzed purely through lexical regex and structural decomposition (e.g., raw IP detection, entropy, deceptive subdomains, suspicious TLDs). No outbound HTTP requests or DNS resolutions are performed.
- **Transmit Data Externally:** All database storage, model inference, and explanation generation run locally on localhost. Zero cloud telemetry or API calls are used.

## 3. System Architecture & Capabilities

```
Raw Email (.eml / .txt / pasted)
          │
          ├──> RFC-822 MIME Parser & Sanitizer
          │         ├── Headers & Authentication (SPF, DKIM, DMARC, Return-Path, Reply-To)
          │         ├── Static URLs (Lexical, IP host, entropy, lookalike domains)
          │         ├── Attachment Metadata (Dangerous extensions, double ext, SHA-256)
          │         └── Body Text (Normalized plain text)
          │
          ├──> Machine Learning & XAI Engine
          │         ├── TF-IDF + Logistic Regression Calibrated Classifier
          │         └── SHAP (LinearExplainer) + LIME Natural Language Synthesizer
          │
          ├──> Module A: Stylometric AI-Authorship Classifier (Human vs. LLM)
          │
          ├──> Module B: Explanation-Guided Adversarial Evaluation Harness
          │
          ├──> Multi-Factor Risk Engine (Weighted 0–100 Score)
          │
          └──> SOC Analyst Presentation Layer (React UI & ReportLab PDF Forensics)
```

## 4. Multi-Factor Risk Scoring Matrix

The compound Risk Score ($0 \le R \le 100$) integrates seven independent analytical vectors:

| Component Factor | Default Weight | Core Detection Indicators |
| :--- | :--- | :--- |
| **ML Phishing Probability** | 30 | Calibrated posterior probability from TF-IDF + Logistic Regression model |
| **URL Static Risk** | 20 | Raw IP addresses, punycode/IDN, excessive subdomains, brand-in-subdomain |
| **Header & Authentication** | 15 | SPF/DKIM/DMARC failure status, Reply-To mismatch, display-name spoofing |
| **Sender/Domain Anomalies** | 10 | Normalized Levenshtein typosquatting distance, Unicode homoglyphs |
| **Social Engineering Triggers** | 10 | Urgency, account suspension threats, credential harvesting, fear appeals |
| **Attachment Risk** | 10 | Executable extensions (.exe, .scr), double extensions (.pdf.exe), macro types |
| **Content Anomalies** | 5 | Massive whitespace padding, hidden CSS styling, zero-width characters |
| **Total** | **100** | Configurable compound score |

### Severity Categorization:
- **0 – 24 (LOW):** Verified authentication; normal business syntax.
- **25 – 49 (MODERATE):** Isolated anomalies detected; manual analyst scrutiny recommended.
- **50 – 74 (HIGH):** Significant phishing indicators; message should be quarantined.
- **75 – 100 (CRITICAL):** Multiple definitive attack vectors present; immediate incident triage.

*(Note: AI-Authorship likelihood and Adversarial Robustness metrics are reported alongside the score as independent analytical dimensions).*

## 6. Quickstart Guide (Local-First Deployment)

### Prerequisites:
- Python 3.11+
- Node.js 18+ and npm

### Backend Setup:
```bash
cd backend
python -m venv venv
# On Windows:
.\venv\Scripts\activate
# On Linux/macOS:
source venv/bin/activate

pip install -r requirements.txt
uvicorn app.main:app --reload --port 8000
```
FastAPI documentation will be available at `http://127.0.0.1:8000/docs`.

### Frontend Setup:
```bash
cd frontend
npm install
npm run dev
```
The React SOC Dashboard will launch at `http://127.0.0.1:5173`.
